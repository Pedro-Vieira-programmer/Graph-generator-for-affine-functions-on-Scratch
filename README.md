# [Graph-generator-for-affine-functions-on-Scratch](https://scratch.mit.edu/projects/1140442345)
## What is this? 🤔
This is a Scratch program that creates a graph for any affine function given by the user. 
## Why did I do this?
I've loved mathematics and programming for a long time. So when I was learning about affine functions in 8th grade, I thought I'd combine the two in a way that would complement my learning and help me create new ways of looking at the subject, so I created the generator to have fun, to learn, to check what I knew and to help my colleagues.
